Drop into Figma

Every file is a standalone SVG with a 1440 × 900 artboard. Import one screen at a time, or open the combined board and place the whole set in a single move.

  1. 01Install the fonts. Add Fraunces and Inter from Google Fonts so headings and body copy render exactly as designed.
  2. 02Import. In Figma choose File → Place image (or drag the SVG) and drop all-screens.svg for the overview, or any file in /svg for a single screen.
  3. 03Keep it editable. Import as SVG rather than flattening. Text becomes text layers, shapes become vectors, and the screen group is named after its flow.
  4. 04Reuse the system. Cards, badges, inputs, buttons, book covers and the sidebar all repeat across screens, so you can build components directly from the imported layers.
